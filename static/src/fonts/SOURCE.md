# Web font sources

The bundled fonts are pinned copies from Fontsource 5.3.0. Fontsource packages
derive their files and metadata from Google Fonts.

- `gowun-dodum-korean-400-v12.woff2`: `@fontsource/gowun-dodum@5.3.0`
- `gowun-batang-korean-400-v12.woff2`: `@fontsource/gowun-batang@5.3.0`
- `gowun-batang-korean-700-v12.woff2`: `@fontsource/gowun-batang@5.3.0`
- `jetbrains-mono-latin-400-v24.woff2`: `@fontsource/jetbrains-mono@5.3.0`

Each family is distributed under the SIL Open Font License 1.1. The matching
license and copyright notice are stored next to the font files.
